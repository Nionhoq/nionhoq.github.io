claude-watch — a Tool That Lets Claude Watch Any Video

By Nion Hoq · Oct 22, 2026 · 1 min read

claude-watch is a free skill that gives Claude the ability to watch a video. You paste a link or a local file. It downloads the video, pulls one frame at each scene change, gets the transcript, and hands both to Claude with a structured report.

The report is the useful part. It has a short summary, the key moments, and a hook microscope that looks closely at the first 0 to 10 seconds, frame by frame, word by word. That is where a reel earns or loses a viewer.

The verdict from the reviewer: FACT. He tested it and stamped it FACT, and the repo backs that up. The code is public, the licence is MIT, and it is still being updated.

Cost: free. Captions cover most public videos at no cost. If a video has no captions, you need a Whisper key for the transcript. The repo points to Groq for that step and calls it the cheaper option.

For me, this fits two jobs. One is competitor reel breakdowns: paste a reel, ask what the hook did. The other is learning from YouTube without watching every minute, which is the base for the video learning system I want to build.

Link: github.com/taoufik123-collab/claude-watch
