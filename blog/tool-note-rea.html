REA — a Free Reverse-Engineering MCP Server

By Nion Hoq · Nov 10, 2026 · 1 min read

REA is an MCP server and CLI that gives coding agents reverse-engineering tools. Point Claude Code, Cursor, Codex or Gemini CLI at software without source and it returns pseudocode, module graphs and request logs, with evidence for each finding.

It covers native binaries through Ghidra, Hopper or IDA, plus Electron and JavaScript apps, .NET, Android APKs and firmware. It does not recover original source. It reconstructs how a feature works.

The creator stamp is FACT. In his test he asked how Granola records meetings without joining one. The run took about five minutes and gave a detailed report that checked out.

Cost is free. REA is open source under MIT and installs with npx rea-agents setup. His test cost $2.24, and that was his own Claude API spend, not a fee for REA.

For me the use is API recon on freelancing gigs and learning how a competitor app works before I build against it. That was the research use in my tracker, including the auto-reel machine work.

Supply-chain angle: EDI and warehouse tools are often closed vendor software with thin docs. A tool that shows what a program actually does, file by file and request by request, helps when you have to integrate with it and no one can explain it.

Link: github.com/morluto/rea
