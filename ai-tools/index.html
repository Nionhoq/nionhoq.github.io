AI Tools I've Tested

I come across a lot of AI tools. When one looks interesting, I look into it properly: what it does, what it costs, and whether the claim behind it holds up in a real test. Some of them I like. A couple I use every week now. Most are good ideas that don't survive contact.

This is my running list, so I don't get sold the same tool twice. Fact means the claim held up in testing. Hype means it didn't, and those stay on the list too. 31 tools so far: 16 held up, 10 landed in the middle, 1 was hype, 4 still need a proper check. Nothing here is sponsored. Try them yourself; the short version of each test is in my tool notes.

    GitHub tool turning Claude Code into a production studio; photo + prompt in, cinematic trailer out

    Cost: ~$10-21 per video ($10 credit start; $12 session + $9.41 video shown) · Why it caught my eye: Brenne Beau reels; YouTube money engine
