Prompts1 / 3

A prompt is a recipe.

Tell AI what you want, add a little context, and name the format. Clear instructions make better answers.

“Explain gravity in three sentences for a curious beginner.”

Noodle says: Goal + context + format. That’s the secret sauce.

Data2 / 3

Data is a pile of examples.

AI finds patterns in examples. Better, more varied examples help it learn better habits—just like practice helps us.

“The treat cupboard opened. Last time, that sound meant snacks…”

Noodle says: Good examples teach good habits.

Double-check3 / 3

Confident isn’t always correct.

AI can sound completely sure and still be wrong. For anything important, pause and check with a reliable source.

“That answer sounds fancy. But is it true?”

Noodle says: Pause, check, then pounce.
